# Тестовое в Only

### Процесс запуска

1.  Установить необходимые пакеты

```
npm install
```

2.  Запустить dev-сервер

```
npm run dev
```

3. Открыть страницу в браузере по соответствующей ссылке (http://localhost:500/)

```
...
<i> [webpack-dev-server] Project is running at:
<i> [webpack-dev-server] Loopback: , http://[::1]:500/
...
```
